HOW TO READ THIS EXPLORER

A consistent season, across 35 years

Explore June 1 through October 30 for selected years from 2021 to 2025. Drag both timeline handles to select one year or a continuous range. Historical annual graphs retain 1991 to 2025 for context. All comparisons use a fixed 1991 to 2020 reference.

Maps and countywide summaries

Each map uses the source product's native grid. Countywide seasonal values weight each pixel by its area inside the county boundary. A selected range averages each year's seasonal value equally. For precipitation this means average seasonal rainfall, rather than the sum of rainfall across several years. A temperature maximum is the season's mean of daily maximum temperatures.

Drought has a different comparison

Hargreaves SPEI compares precipitation minus temperature-based potential evapotranspiration with the historical seasonal water balance. Negative values indicate dry conditions and positive values indicate wet conditions.

Why SPEI ≤ −1? The foundational SPI paper by McKee, Doesken, and Kleist (1993) used −1 as the entry to moderate drought; Vicente-Serrano, Beguería, and López-Moreno (2010) introduced SPEI by adding evaporative demand to the standardized-index framework. The seven moisture bands below follow the conventional SPI classification documented in WMO (2012), Table 1, applied here to the SPEI scale. The sources have distinct roles: Reference 1 documents the threshold’s origin, Reference 2 the SPEI method, and Reference 3 the full seven-class convention.

Intervals use the unrounded SPEI. Values exactly −1, −1.5, or −2 belong to the corresponding drier class; values exactly 1, 1.5, or 2 belong to the corresponding wetter class. These continuous intervals implement the published cutoffs without the gaps that a printed two-decimal table can suggest. Near normal includes both slightly negative and slightly positive values.

The same definition throughout: a dry season is any of the first three rows, so the dry-season-frequency map and the countywide dry-area graph both use SPEI ≤ −1. This explorer counts each June 1 to October 30 season independently. Climate Engine calculates this product with Hargreaves potential evapotranspiration and nonparametric standardization against 1991 to 2020; the original SPEI method paper provides the conceptual foundation.

For one year, compare the index with seven moisture classes. For several years, each source pixel shows the number of selected annual seasons with SPEI ≤ −1, divided by the number of selected seasons, multiplied by 100. We apply exactly the same cutoff and calculation to all 30 reference seasons. For example, two dry seasons out of five give 40%; one dry season out of 30 reference seasons gives about 3.3%.

This frequency calculation is this explorer’s summary of annual dry-season classifications. It describes observed seasonal frequency, rather than the share of dry days or a forecast of future fire probability. The class graph averages annual area percentages. It never classifies an average SPEI. Day-by-day source coverage is not independently audited for these standardized seasonal rasters.

Daily graphs

Daily series are Climate Engine regional means from the simplified query boundary. Seasonal maps and annual graphs use native pixels intersected with the full county boundary. These spatial methods differ, so daily cumulative precipitation can differ slightly from the mapped seasonal total. Daily and weekly comparisons use matching calendar days; precipitation is cumulative. A missing source day remains a visible gap, including in multi-year daily comparisons.

One approved source gap

CEMS has no FWI observation for August 8, 2024 in this source collection. The 2024 seasonal mean uses 151 of 152 days (99.34%), with no interpolation. The baseline excludes 2024. This note follows any selected range and export that includes 2024 FWI.
